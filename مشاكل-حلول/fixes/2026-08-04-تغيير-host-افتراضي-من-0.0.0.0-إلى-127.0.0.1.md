# حل: تغيير الـ host الافتراضي من `0.0.0.0` إلى `127.0.0.1`

- **التاريخ**: 2026-08-04
- **النوع**: fix
- **الوضعية**: reviewer
- **الحالة**: open
- **الأولوية**: low
- **الملف المستهدف**: `backend/app/core/config.py:16`

## الوصف

`host` يُعرّف افتراضياً كـ `"0.0.0.0"` — هذا يربط Uvicorn على **جميع واجهات الشبكة** بشكل افتراضي. في بيئة تطوير محلية، هذا غير الضروري ويزيد سطح الهجوم.

## الحل

```python
# backend/app/core/config.py
class Settings(BaseSettings):
    host: str = "127.0.0.1"    # ← تغيير من 0.0.0.0 إلى 127.0.0.1
```

للإنتاج عبر Docker، استخدم `0.0.0.0` صراحة في `docker-compose.yml` أو Dockerfile:
```yaml
# docker-compose.yml — backend service
environment:
  - HOST=0.0.0.0
```
