# حل: `assert` في كود إنتاج — استبدال بفحص صريح

- **التاريخ**: 2026-08-04
- **النوع**: fix
- **الوضعية**: reviewer
- **الحالة**: open
- **الأولوية**: medium
- **الملف المستهدف**: `backend/app/books/service.py:274`
- **المشكلة المرتبطة**: security-audit (ruff S101)

## الوصف

`assert lesson is not None` في كود إنتاج. إذا تم تشغيل Python بـ flag `-O` (optimizations) — كما في بعض Docker images الرياضية — فإن جميع `assert` يتم إزالتها، مما يؤدي إلى `None` dereference بدلاً من الرسالة الخطأ المقصودة.

## الحل

```python
# BEFORE:
assert lesson is not None

# AFTER:
if lesson is None:
    raise ValueError(
        f"Lesson not found in book {book_id} lesson {lesson_id}"
    )
```
