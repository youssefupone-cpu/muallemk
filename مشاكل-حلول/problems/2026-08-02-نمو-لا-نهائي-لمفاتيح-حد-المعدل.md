# نمو غير محدود لمفاتيح حد المعدل في الذاكرة

- **الحالة**: fixed (2026-08-02 — حلقة إصلاحات المراجعة، Development)

## الحل المنفذ
دالة `_gc(now)`: تُستدعى من `check` عند تجاوز `_limits` عتبة 512 مفتاحاً
(وتُشترط مرور 60 ثانية بين عمليات التنظيف) وتحذف المفاتيح التي انتهت نوافذها
بأكملها (`now - q[-1] > _GC_INTERVAL`).
- **التصنيف**: Minor
- **الموقع**: `backend/app/core/rate_limit.py:13`

## المشكلة
```python
_limits: dict[tuple[str, str], deque[float]] = defaultdict(deque)
```
المفاتيح `(path, host)` لا تُحذف أبداً حتى بعد انتهاء نافذتها؛ الـ deque يُفرَّغ
لكن المفتاح يبقى في القاموس. مع تعرّض الخادم لعناوين/مسارات جديدة باستمرار (سبر،
منافذ عامة) ينمو القاموس بلا سقف.

## الحل المقترح
تنظيف دوري (كل بضع دقائق) للمفاتيح التي انتهت نوافذها، أو تحويل النافذة المنزلقة
إلى عدّاد Fixed Window بسيط مع `ttl` لكل مفتاح، أو سقف أقصى لحجم القاموس.
