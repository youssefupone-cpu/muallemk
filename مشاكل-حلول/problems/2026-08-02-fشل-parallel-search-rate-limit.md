# فشل خادم Parallel Search (Rate Limit)

- **التاريخ**: 2026-08-02
- **الحالة**: open (تم الالتفاف عليه ببديل — لم يُحل)
- **النوع**: مشكلة بنية تحتية

## الوصف
خادم `parallel-search` MCP رفض جميع استدعاءات `web_search` (3 استدعاءات متوازية في نفس الدفعة) برسالة:
`You've hit the free-tier rate limit for Parallel Search MCP...`

السبب المرجح: استنفاد حصة الاستخدام المجانية (free-tier) — على الأرجح لأن عدة طلبات أُرسلت دفعة واحدة، أو لأن الحصة المجانية وصلت سقفها اليومي.

## الحل المطبق (بديل)
استُخدمت أداة `websearch` المدمجة في opencode (مع session_id مختلف) — عملت بنجاح وجلبت نتائج كافية للإجابة.

## الحل الموصى به مستقبلاً
1. إرسال استدعاءات parallel-search واحدة تلو الأخرى بدل الدفعات المتوازية (الحصة تسمح بعدد أقل متزامن).
2. إضافة مفتاح API من https://platform.parallel.ai عبر `x-api-key` أو `Authorization` في إعدادات MCP.
3. أو الاعتماد الافتراضي على أداة `websearch` المدمجة كخادم أساسي عند استنفاد الحصة.
