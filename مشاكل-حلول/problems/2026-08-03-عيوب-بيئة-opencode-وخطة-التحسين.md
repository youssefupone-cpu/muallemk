## الوصف

فحص شامل لبيئة opencode (`~/.config/opencode/`) وكيفية عملها، ثم بحث عبر 3 وكلاء بحث متوازيين عن أفضل تكوين لتحقيق أعلى أداء وكفاءة. النتيجة: 12 عيباً محدداً بالأدلة، وأفضل الممارسات الموثقة، وخطة تحسين بالأولوية.

## أفضل الممارسات من البحث (بالمصادر)

1. **حد أقصى 3–4 خوادم MCP مفعّلة دائماً** — ما بعدها تفوق التكلفة الفائدة (mcpplaygroundonline.com، docs.bswen.com: 15 خادماً = ~100K رمز).
2. **تقليم أدوات GitHub إلى ~5** (get_repository, list_pull_requests, get_pull_request, list_issues, search_code) — تغطي 90% من العمل وتوفر ~80% من التكلفة (getunblocked.com).
3. **التحميل الكسول (Lazy Loading)** — نمط معتمد رسمياً (Anthropic Context Engineering؛ opencode docs/rules: "Do NOT preemptively load all references"). Plugin مجتمعي `opencode-lazy-loading` يوفر 98.7% (24.8K ← 323 رمزاً). feature مدمجة قيد الدمج (PR #8771/#12520).
4. **CLI بدل MCP للاستخدام النادر** — gh بدل GitHub MCP، Playwright CLI بدل الخادم: أرخص 4–32x (onlycli.github.io، scalekit.com).
5. **مفاتيح عبر `{env:VAR}`** — opencode يدعم التوسيع البيئي رسمياً (opencode.ai/docs/config).
6. **`small_model` لنموذج محلي خفيف** (مثل qwen3:4b) — لمهام التلخيص/العناوين.
7. **AGENTS.md ≤ 200 سطر** (Anthropic رسمي) مع نمط lazy loading للمراجع.
8. **قواعد scoped بالمسار** بدل التضمين الكامل — توفير فعلي (code.claude.com/docs).
9. **التثبيت المحلي الدائم للخوادم** بدل npx -y (taekyo-lee.github.io).
10. **ضبط compaction**: `reserved` حاجز أمان + `tail_turns` 4–8 توازناً + `tool_output` 300–500 سطر/16KB.

## خطة التحسين المقترحة (بالأولوية)

### P0 — أمني (فوري)
1. نقل مفاتيح GitHub/Context7 من `opencode.json` إلى متغيرات بيئة + `{env:VAR}`.
2. تصحيح أو حذف تعريف wigolo (الأمر خاطئ — الحزمة `wigolo` وليست `wigolo-server`)؛ توثيقه في env/servers إن أُبقي.

### P1 — أداء (ربح فوري 50–90K رمز/طلب)
3. تقليص الخوادم المفعلّة دائماً إلى 4: `codebase-memory-mcp` + `context7` + `parallel-search` + `sequential-thinking` — والباقي `enabled: false` (playwright، github، filesystem، memory، codegraph، linkedin-scraper، squish، magic، vercel، cloudflare-docs، railway، graphify، evalview، wigolo) يُفعَّل عند الحاجة.
4. تقليم أدوات github إلى 5 عند تفعيله.
5. دمج/إزالة التكرار: codegraph + graphify ← codebase-memory-mcp؛ memory ← squish أو العكس.
6. إزالة خوادم المنصات النادرة نهائياً أو تعطيلها (vercel, railway, cloudflare-docs, linkedin-scraper, magic, evalview).
7. تثبيت الخوادم الأساسية محلياً (npm i -g) بدل npx -y.

### P2 — سياق (التزام أعلى)
8. إعادة هيكلة AGENTS.md إلى ≤150 سطر (قواعد حتمية فقط) + ملفات مرجعية عند الطلب (مهارات/أدوات/تصميم).
9. توحيد مصدر الحقيقة: agent/*.md = وصف قصير فقط → تفاصيل في modes/*/README.md.
10. `small_model` محلي خفيف في opencode.json.

### P3 — ضبط دقيق
11. `tail_turns: 5`، إضافة `compaction.reserved: 10000`، `tool_output: 400/16384`.
12. إضافة `watcher.ignore` (node_modules/**، .git/**، .venv/**) + `snapshot: false` للمستودعات الضخمة.
13. `external_directory: ask` بدل allow.

## ✅ الإصلاح المنفذ (2026-08-03)

### P0 — أمني
1. **نقل المفاتيح**: `GITHUB_PERSONAL_ACCESS_TOKEN` و`CONTEXT7_API_KEY` انتقلتا من `opencode.json` إلى `~/.bashrc` (export) وأصبح المرجع `{env:VAR}` — 0 مفاتيح نصية صريحة متبقية (تحقق: `grep -c "ghp_\|ctx7sk-"` = 0).
2. **wigolo**: صُحّح الأمر إلى `npx -y wigolo`، عُطّل افتراضياً (`enabled: false`)، ووثّق في `env/servers/README.md`؛ حُذف `config.json` المنفصل (توحيد التكوين في `opencode.json`).

### P1 — أداء
3. **تقليص الخوادم**: 4 مفعّلة فقط (codebase-memory-mcp، context7، parallel-search، sequential-thinking) و14 معطلة `enabled: false` (تحقق: `jq` — 4 مفعّلة/14 معطلة).
4. **تقليم github**: `tools: {"github_*": false, +5 أدوات محددة}` في `opencode.json`.
5. **إزالة التكرار**: codegraph + graphify + memory + squish → معطلة (يبقى codebase-memory-mcp).
6. **خوادم المنصات النادرة**: vercel, railway, cloudflare-docs, linkedin-scraper, magic, evalview → معطلة.
7. **توثيق الحالة**: `env/servers/README.md` جديد يشرح المفعّل/المعطل وكيفية التفعيل اليدوي.

### P2 — سياق
8. **AGENTS.md**: من 452 سطراً/33KB → **39 سطراً/4.8KB** (قواعد حتمية فقط) + 5 ملفات مرجعية جديدة في `rules/` تُقرأ عند الحاجة (workflow، skills، design-architecture، testing-gate، issues).
9. **توحيد مصدر الحقيقة**: agent/*.md من 410 سطراً → **94 سطراً** (frontmatter + إحالة إلى `modes/*/README.md` فقط).
10. **small_model**: `ollama/qwen3.5:2b-q4_K_M` (متوفر محلياً) + تعريفه في provider.

### P3 — ضبط دقيق
11. `tail_turns: 5` + `compaction.reserved: 10000` + `tool_output: 400/16384`.
12. `watcher.ignore` (node_modules، dist، build، .git، .venv، __pycache__، .next، coverage).
13. `external_directory: ask` بدل allow.

### التحقق النهائي
- `jq -e . opencode.json` → ✓ صالح.
- 4 خوادم مفعّلة / 14 معطلة → ✓.
- صفر مفاتيح مكشوفة في opencode.json → ✓.
- `config.json` محذوف → ✓.

### ⚠️ متبقٍ على المستخدم
- **تدوير (rotate) المفتاحين**: كانا نصاً صريحاً في opencode.json — إن نُشر الملف أو شاركته في أي نسخة احتياطية عامة، أعد إصدار `GITHUB_PERSONAL_ACCESS_TOKEN` (GitHub Settings → Developer settings → Tokens) ومفتاح Context7 ثم حدّث `~/.bashrc`.
- تشغيل جلسة opencode جديدة لتحميل الإعدادات (إعادة فتح المحطة يكفي لتحميل متغيرات البيئة).
