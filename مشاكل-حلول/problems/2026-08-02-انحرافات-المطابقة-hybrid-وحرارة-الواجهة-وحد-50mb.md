# انحرافات المطابقة: hybrid ناقص + حرارة غائبة من الواجهة + حد 50MB + reranker غير مثبت

- **التاريخ**: 2026-08-02
- **النوع**: problem (انحراف عن الخطة المعتمدة PLAN.md v3.1)
- **الوضعية**: matching
- **الحالة**: open
- **الأولوية**: medium

## 1. استرجاع hybrid (vector + FTS) غير منفّذ — م6
- **المطلوب** (PLAN.md م6): «استرجاع hybrid» عبر LanceDB.
- **الفعلي**: `backend/app/rag/engine.py` — بحث تضمين (vector) فقط؛ لا `fts`/`bm25`/`hybrid` في أي ملف rag (`grep -rn "hybrid\|bm25\|fts" backend/app/rag/` → لا شيء).
- **التخفيف الحالي**: Reranker يعوض جزئياً عند التفعيل.
- **الحل المقترح**: `tbl.create_scorer_index` / `search(..., query_type="hybrid")` على عمود النص في LanceDB (موثق رسمياً في مقارنة 2026 بالخطة) + دمج درجات vector/fts.

## 2. «الحرارة» (temperature) غائبة من صفحة الإعدادات — م4
- **المطلوب** (م4): صفحة إعدادات (المزوّد/النموذج/المفتاح/**الحرارة**).
- **الفعلي**: `frontend/src/lib/settings.ts` و`SettingsPage.tsx` — provider/model/baseUrl/apiKey فقط؛ لا حرارة. الباكند يدعمها (`backend/app/core/llm/base.py:23` default 0.7 ويمررها LiteLLMProvider) لكن الواجهة لا ترسلها.
- **الحل المقترح**: إضافة `temperature?: number` إلى `ProviderSettings` + منزلق في صفحة الإعدادات + تمريرها في الطلبات (chat/ask/report).

## 3. حد رفع 50MB غير مطبّق — م5
- **المطلوب** (م5): «رفع ... حد 50MB».
- **الفعلي**: لا تحقق من الحجم في `documents/service.py` أو `documents/router.py` (grep size/50 → لا شيء).
- **الحل المقترح**: فحص `file.size` قبل المعالجة → 413 «الملف يتجاوز 50MB».

## 4. نموذج bge-reranker-v2-m3 غير مثبت محلياً — م6 (بيئي)
- **الفعلي**: الكود سليم (`backend/app/rag/reranker.py` مع fallback أنيق «يعيد الأصلية عند الفشل»)، لكن `ollama list` لا يعرض bge-reranker-v2-m3 → reranker في وضع `_available=False` عملياً على هذا الجهاز.
- **الحل**: `ollama pull bge-reranker-v2-m3` عند توفر الشبكة؛ أو تغيير الافتراضي لنموذج مثبت.

## ملاحظات مطابقة إيجابية مؤكدة بالفحص
