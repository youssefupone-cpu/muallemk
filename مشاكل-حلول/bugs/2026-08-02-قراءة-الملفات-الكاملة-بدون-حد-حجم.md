# قراءة الملفات المرفوعة كاملة في الذاكرة بلا حد حجم (DoS)

- **التاريخ**: 2026-08-02
- **النوع**: bug (أمان/أداء — استنزاف موارد)
- **الوضعية**: reviewer
- **الحالة**: open
- **الأولوية**: major

## الوصف
`backend/app/documents/service.py:75`:
```python
raw = upload.file.read()
```
يقرأ الملف كاملاً في الذاكرة بلا أي حد للحجم (متعلق بانحراف المطابقة «حد 50MB غير مطبّق — م5»).

## السبب الجذري
لا فحص `file.size` قبل القراءة، و`UploadFile.read()` بلا وسيطة يقرأ الكل دفعة واحدة.

## الأثر
- ملف 2GB → محاولة تحميل 2GB في الذاكرة (FastAPI/uvicorn) → DoS أو انهيار.
- الصور تمر عبر `PIL.Image.open` (documents/service.py:61) — صور ضخمة (decompression bombs) تُعالج بـ tesseract بلا حدود.

## الحل المقترح
1. قبل القراءة: `if file.size and file.size > 50 * 1024 * 1024: raise HTTPException(413, "الملف يتجاوز 50MB")`.
2. قراءة مُقيّدة: `raw = await file.read(MAX + 1)` ثم إن تجاوز → 413 (يمنع القراءة الكاملة أصلاً).
3. في OCR: فحص أبعاد الصورة (`Image.MAX_IMAGE_PIXELS` أو تحقق `img.size`) قبل `image_to_string`.
