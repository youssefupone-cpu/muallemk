# `.env` يُحمّل API Keys داخل الحاوية — تسريب الأسرار

- **التاريخ**: 2026-08-04
- **النوع**: bug (secrets management / Docker)
- **الوضعية**: reviewer
- **الحالة**: fixed
- **الأولوية**: high
- **الملف**: `docker-compose.yml:5-6`

## الوصف

`docker-compose.yml` يستخدم `env_file: .env` لتحميل **كل ملف البيئة** (بما فيها `OPENAI_API_KEY`، `ANTHROPIC_API_KEY`، `TAVILY_API_KEY`، إلخ) **داخل الحاوية**. هذا يعني أن مفاتيح API تُخزن كـ environment variables داخل الحاوية — ويمكن الوصول إليها عبر `/proc/1/environ` إذا تم اختراق الحاوية.

## الأدلة

```yaml
# docker-compose.yml
services:
  backend:
    build: .
    env_file:
      - ./.env                # ← كل المتغيّرات بما فيها API keys
    # ← required: false — إذا فشل التحميل، الخدمة تستمر بدون config (silent insecure fallback)
```

```bash
# .env.example (566 خطوط — يوثّق كل المتغيّرات بما فيها secrets)
OPENAI_API_KEY=
ANTHROPIC_API_KEY=
TAVILY_API_KEY=
```

## التأثير

1. **Container introspection**: أي ثغرة RCE داخل الحاوية تكشف `printenv` أو `/proc/1/environ` → سرقة جميع API keys.
2. **Image snapshotting**: إذا أُلتقطت صورة Docker للـ container (volume snapshot)، تُحتفظ فيها المفاتيح في بيئتها.
3. **Docker socket access**: إذا كان أحد الأدوات أو CI يملك `docker.sock`، فهو يملك `docker exec backend printenv` → كل المفاتيح.
4. **Silent fallback**: `env_file` بلا `required: true` — إذا لم يُعثر على `.env`، تستمر الخدمة بقيم افتراضية غير آمنة.

## الحل

**استراتيجية: Docker secrets أو CI-only env vars**

```yaml
# الطريقة الآمنة — فقط المتغيّرات غير-Secret عبر env_file
services:
  backend:
    build: .
    secrets:
      - openai_api_key
      - anthropic_api_key
      - tavily_api_key
    environment:
      # المتغيّرات العامة فقط (ليست secrets)
      - OLLAMA_BASE_URL=http://ollama:11434
      - SEARXNG_URL=http://searxng:8080
      - DOCS_ENABLED=false
      - CORS_ORIGINS=https://your-domain.com
    env_file:
      - .env.production      # ← فقط non-secret vars
    secrets:
      - openai_api_key

secrets:
  openai_api_key:
    external: true          # ← يتم تحميله من CI/secrets manager
  anthropic_api_key:
    external: true
```

**بديل أبسط (للـ dev)**: استخدم environment variables من CI فقط — لا `env_file` في compose للإنتاج.
