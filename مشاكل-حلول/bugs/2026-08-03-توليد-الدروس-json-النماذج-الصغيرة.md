# توليد الدروس: نماذج LLM الصغيرة (gemma3:1b) لا تلتزم بصيغة JSON العميقة

- **التاريخ**: 2026-08-03
- **النوع**: bug
- **الوضعية**: build
- **الحالة**: fixed
- **الأولوية**: medium

## الوصف

عند التوليد الحي لدرس عبر Ollama (`gemma3:1b-it-qat`) فشل توليد JSON: النموذج
أخرج بنية JSON مع فاصلة زائدة (`Expecting ',' delimiter: line 12 column 126`)
ففشل `json.loads` ووُسم الدرس `failed` — بينما اختبارات FakeLLM كانت خضراء لأن
النموذج الوهمي يلتزم بالصيغة تماماً.

## الخطوات لإعادة الإنتاج

1. رفع كتاب نصي صغير → تحليل → توليد درس واحد عبر Ollama gemma3:1b.
2. يُرصد في سجل الخادم `JSONDecodeError: Expecting ',' delimiter` وحالة الدرس `failed`.

## السبب الجذري

النماذج الصغيرة (1B) تُخرِج JSON سليماً هيكلياً لكن مع أخطاء علامات ترقيم شائعة
(فاصلة زائدة قبل `]`/`}`)، وأحياناً نصاً زائداً خارج الكائن.

## الحل / الإصلاح

1. `app/books/service.py::_repair_json` — إصلاح تلقائي: إزالة الفواصل الزائدة قبل
   `]`/`}`، واقتصاص النص عند آخر `}`.
2. `_extract_json` — ثلاث محاولات: سياج markdown → أول `{` حتى آخر `}` → النص
   الخام (بعد الإصلاح الخفيف).
3. عند فشل كل المحاولات: استدعاء ثانٍ خفيف بدرجة حرارة 0.3 مع تعليمة «JSON فقط».

## الملفات المتأثرة

- `backend/app/books/service.py` (GENERATE_SYSTEM، _repair_json، _extract_json، generate_lesson)

## التحقق

- اختبارات `tests/test_books.py` (12) خضراء، والفحص الكامل 93 ناجحاً.
- توليد حي على درس «أهمية الماء»: `status: ready` + شرح + 2 أسئلة + 1 تدريب.
