# خطأ 500 غير معالج عند استدعاء إضافة بمعاملات لا يقبلها توقيعها

- **التاريخ**: 2026-08-02
- **النوع**: bug
- **الوضعية**: tester
- **الحالة**: fixed
- **الأولوية**: high

## الوصف
استدعاء `/plugins/{name}/invoke` بجسم يحتوي `action` (أو أي مفتاح) لا يقبله توقيع `run()` في الإضافة يُرجع `500 Internal Server Error` بجسم فارغ — بدلاً من استجابة `{"status": "error", "error": ...}` الموثقة في docstring الراوتر (`backend/app/plugins/router.py:129-133`).

## الخطوات لإعادة الإنتاج
1. شغّل الخادم.
2. `POST /plugins/grades-tool/invoke` بجسم `{"action": "default"}` — grades-tool تُعرّف `run(ctx, grades)` بلا معامل `action`.
3. لاحظ `500 Internal Server Error`.

## السلوك الفعلي
`http=500 body=Internal Server Error` — استثناء غير ممسوك يتسرب من الـ handler (FastAPI يحوّله إلى 500).

## السلوك المتوقع
استجابة 200 مع `{"name": ..., "result": null, "status": "error", "error": "فشل التنفيذ: ..."}` — أي فشل مُحتوى ضمن عزل الإضافات (كما يصمّم `Plugin.run` في `manager.py:128-140`).

## السبب الجذري
سببان مترابطان في `backend/app/plugins/manager.py`:
1. `accepts()` الجديدة تستخدم `inspect.signature` **دون استيراد `inspect`** → `NameError: name 'inspect' is not defined` يقع خارج أي try في `invoke_plugin` → 500.
2. الراوتر يمرر **كل** جسم الطلب `p.run(**body)` — بما فيه `action` الذي لا تقبله إضافات مثل grades-tool → عند تصفية الـ kwargs يظهر نقص معامل مطلوب (`grades`) — وهنا سلوك معالج صحيح (error أنيق) وليس 500.

## الحل / الإصلاح
في `backend/app/plugins/manager.py`:
- إضافة `import inspect` (أعلى الوحدة).
- إضافة دالة `Plugin.accepts(param)` تعيد `param in inspect.signature(mod.run).parameters` (تعيد False عند غياب الوحدة/الدالة).
في `backend/app/plugins/router.py:146-147` (`invoke_plugin`):
- تصفية جسم الطلب إلى المعاملات المقبولة فقط:
  `kwargs = {k: v for k, v in body.items() if p.accepts(k)}`
  ثم `result = await p.run(**kwargs)`.
- الإضافات التي تقبل `action` (books/reports) تتلقاه كما هو — لا تغيير في سلوكها.

## الملفات المتأثرة
- `backend/app/plugins/manager.py` (import inspect + accepts)
- `backend/app/plugins/router.py` (تصفية kwargs في invoke_plugin)
