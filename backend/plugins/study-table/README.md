# study-table — إضافة «جدول الدراسة» (ui-page)

> **عقدة موثّقة (P1-93):** هذه الإضافة لا تحمل `run.py` — هذا **مقصود وليس نقصاً**.

## لماذا بلا run.py؟

- نوع الإضافة هو `ui-page`: صفحة React تُرسم تلقائياً من `ui.schema` المعلن في
  `manifest.json` (يوم/مادة/وقت/ملاحظات) وتخزّن في `PluginContext.data/ui.json`.
- لا توجد إجراءات خادم (`actions`) — كل المنطق تخزين محلي في المتصفح/السياق.
- أي `invoke` على هذه الإضافة يجب أن يرفضه المدير بـ 400 («لا إجراءات»)،
  وهو السلوك الصحيح: لا دالة تُستدعى لأن لا منطق خادم.

## لماذا وُجدت أصلاً؟

خط الدراسة الأسبوعي هو ميزة مستقلة بذاتها (تخطيط + حفظ + تعديل) — إبقاؤها
إضافة يسمح بتفعيلها/تعطيلها كوحدة واحدة، ويُبقي نواة المعلّمك نظيفة.

## التعامل المستقبلي

- لو أردنا لاحقاً إجراءات خادم (مثلاً: توليد خطة LLM أسبوعية) → نضيف
  `run.py` بإجراءات `generate-plan` وما شابه، ولا نضيفه الآن بلا حاجة.
