
## توقيع غير موحّد (P3-79 — استثناء موثّق)

\`run(ctx, grades)\` يختلف عن باقي الأدوات (التي توقع \`run(ctx, action, payload)\`).
السبب: هذه الأداة أداة حاسبة بسيطة لا تحتاج \`action\`، والواجهة ترسل
\`grades\` كـ form-data → \`accepts('grades')\` يمرره مباشرة. لا يُعَدّ توحيد
التوقيع لأنه يكسر المنحنى التكيفي الحالي.
